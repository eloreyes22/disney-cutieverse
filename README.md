
# ✨ Disney Cutieverse

Disney Cutieverse es un portal web interactivo que permite
explorar personajes del universo Disney mediante el consumo
de una API pública.

## 🎀 Descripción

El proyecto fue desarrollado como práctica de la asignatura
Diseño de Internet, con el objetivo de implementar peticiones
HTTP y mostrar información dinámica utilizando JavaScript.

Los usuarios pueden buscar personajes, visualizar imágenes,
explorar el catálogo y consultar fichas detalladas.

## 🌸 Tecnologías utilizadas

- HTML5: estructura del portal.
- CSS3: diseño visual y adaptable.
- JavaScript: funcionalidades e interactividad.
- Fetch API: consumo de servicios web.
- JSON: procesamiento de datos.
- Git y GitHub: control de versiones.

## 💗 Funcionalidades

- Catálogo dinámico de personajes Disney.
- Búsqueda de personajes por nombre.
- Carga progresiva de resultados.
- Tarjetas con imágenes e información.
- Fichas detalladas mediante identificadores.
- Consulta de películas, series y videojuegos.
- Visualización de respuestas HTTP y JSON.
- Manejo de errores en peticiones.

## 🌐 API utilizada

Disney API

Documentación: https://disneyapi.dev/

Endpoints utilizados:

GET /character

GET /character?name=Stitch

GET /character/{id}

## 💻 Ejecución del proyecto

1. Descargar o clonar el repositorio.
2. Abrir la carpeta en Visual Studio Code.
3. Ejecutar index.html utilizando Live Server.
4. Explorar el catálogo de personajes.

Se requiere conexión a internet para consultar la API.

## 📚 Asignatura

Diseño de Internet

Proyecto académico desarrollado con HTML, CSS y JavaScript.

## 💖 Créditos

Los datos de personajes se obtienen mediante Disney API.
Los personajes e imágenes pertenecen a sus respectivos
titulares de derechos.
